# Annexe — Les grands arrêts utilisés dans le tome {.simple}

La présente annexe récapitule les décisions citées, classées par juridiction et par ordre chronologique. Les décisions françaises sont utilisées à titre historique et comparatif : elles n'ont pas d'autorité juridique propre en Côte d'Ivoire. Les décisions ivoiriennes sont citées sous la référence qui a pu être établie ; leur texte intégral doit être consulté avant toute utilisation.
